# KeyCreator — direct CAD with manufacturing drawing views

KeyCreator keeps one named board on the desk: the live solid body, the drawing view in front of you, and a short note the next machinist can read. Extra models wait for their own title.

## Session Card

| Slice | What you do in KeyCreator | What remains |
|-------|------------------------|--------------|
| Arrival | Open KeyCreator and name today's shop CAD | A titled CAD body |
| Focus | Keep only live bodies on the KeyCreator board | A short drawing-view list |
| Check | Read KeyCreator manufacturing model before a large view change | A confirmed shop CAD |
| Handoff | Mark finished views inside KeyCreator | A note for the next machinist |

## How KeyCreator Sits

KeyCreator does not replace the unlabeled solid dump, the paper drawing stack, or the second CAD seat you already keep. It sits beside them as a named shop CAD for one job: which direct CAD body is live, which manufacturing model still matches the drawing views, and what the next machinist should read.

If two people share a shop PC, each keeps a KeyCreator style of their own. Extra models wait for their own title instead of crowding the live body.

A first visit should be one short drawing view, then the same KeyCreator shop CAD the next day. That is enough to see if the named CAD body holds.

## Traffic Light

| Signal | On the KeyCreator board | What you do |
|--------|----------------------|-------------|
| Green | Named CAD body, short live view list | Continue the same direct CAD |
| Amber | Two jobs mixed on one manufacturing model | Split the views before a large change |
| Red | No title, no note, drawing views on another file | Stop and name the shop CAD first |
| Clear | Handoff written, live views few | Close KeyCreator and leave the shop CAD |

## Open Order

1. Open the last KeyCreator shop CAD, not a new empty CAD body.
2. Read the drawing views and the last handoff.
3. Finish one visible manufacturing model pass inside KeyCreator.
4. Write what changed, then close with fewer unlabeled solids than you found.
5. If the file feels crowded, drop anything that belongs to a different KeyCreator job.

## After a Week

A week in KeyCreator is not a larger pile of unlabeled solids. It is the same title, a shorter live view list, and a note that still makes sense before the next drawing from the solid. Take finished views off the live set so the next visit starts on the shop CAD that is still open.

Other programs stay where they are. KeyCreator only keeps the path back: file name, direct CAD body, drawing views, handoff.

## Sign-off

- [ ] The KeyCreator workspace name is short enough to scan
- [ ] Only live drawing views sit on the manufacturing model
- [ ] A second machinist can read the shop handoff
- [ ] The last KeyCreator CAD body still opens after a restart
- [ ] Finished views are off the live KeyCreator set
- [ ] The KeyCreator summary still matches the drawing views on the board

## Field Note

KeyCreator is easier to trust when the shop CAD stays smaller than the unlabeled solid dump it came from. Name the CAD body, keep the live drawing views, finish one visible manufacturing pass, and write what changed.

The same loop fits a floor job, a client packet, or a shared shop PC. Open the last KeyCreator file and continue. Do not rebuild the manufacturing model from scratch.
